# 视频取谱工具

在 Windows 上把本地视频中已经显示的吉他六线谱裁出来，按每行 4 小节拼接并导出 PDF。可从多个画面收录连续小节，软件会尝试对齐弦线。

## 安装和启动

- Windows，带 Tk 的 Python 3.10 或更新版本，以及 Windows 的微软雅黑字体。
- 在项目目录运行 `python -m pip install -r requirements.txt` 安装 Pillow。
- 准备 FFmpeg。可以把它加到 PATH，或在工具提示时选择本地的 `ffmpeg.exe`。
- 双击 `启动取谱工具.cmd`，或在项目目录运行 `python app.py`。

## 使用

1. 打开视频。拖动进度条或输入时间定位到有谱的画面。
2. 沿起止小节线框住谱面，上下留出和弦名、弦线和节奏符号。点击框里的小节数量。
3. 从下一小节继续框选。一行可一次加入 4 小节，也可跨画面补齐。工具未识别到弦线时，在框内右键点最上面那条弦线。
4. 用「预览谱面」核对顺序和接缝。选错可撤回。导出 PDF 时，最后不足 4 小节也会保留。

视频在本机处理。工具无法从音频扒谱，也无法识别不同画面里重叠的小节，请自行核对。关闭窗口前请导出，选区不会跨会话保存。
